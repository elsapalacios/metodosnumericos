El método de Euler

La forma más simple de aproximar, paso a paso, la solución de un problema de valor inicial.

Problemas de valor inicial

Un problema de valor inicial (PVI) tiene la forma y' = f(x, y), con y(x₀) = y₀. Muchas ecuaciones diferenciales de este tipo no tienen solución analítica cerrada, así que se aproxima la solución en una malla de puntos x₀, x₁ = x₀ + h, x₂ = x₀ + 2h, …, separados por un paso h.

Fórmula de Euler

El método de Euler usa la pendiente de la solución en el punto actual —dada directamente por f(xn, yn)— para avanzar linealmente hasta el siguiente punto:

yn+1 = yn + h · f(xn, yn)

Geométricamente, equivale a seguir la recta tangente a la solución en xn durante un paso de longitud h, en lugar de seguir la curva real.

Error de truncamiento

Al usar solo el primer término de la serie de Taylor, cada paso introduce un error local del orden O(h²). Acumulado a lo largo de todos los pasos necesarios para cubrir un intervalo, el error global resulta ser de orden O(h): reducir h a la mitad reduce aproximadamente a la mitad el error total, pero duplica el número de pasos (y por tanto el costo).

Ejemplo en Python

Para y' = y, y(0) = 1 (cuya solución exacta es y = eˣ), el método de Euler se implementa así:

def euler(f, x0, y0, h, n_pasos):
    x, y = x0, y0
    for _ in range(n_pasos):
        y = y + h * f(x, y)
        x = x + h
    return x, y

f = lambda x, y: y
x_final, y_aprox = euler(f, 0, 1, 0.1, 10)
print('y aproximado en x=1:', y_aprox)
# Comparar con el valor exacto: e**1

Idea clave

Euler es el punto de partida conceptual de todos los métodos siguientes: Taylor y Runge-Kutta persiguen la misma idea —avanzar usando la pendiente de la solución— pero de forma más precisa por paso.
