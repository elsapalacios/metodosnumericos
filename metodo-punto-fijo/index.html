Método de iteración de punto fijo

Reescribir f(x) = 0 como x = g(x) e iterar hasta que la sucesión se estabilice.

Formulación del problema

Dada una ecuación f(x) = 0, se reescribe algebraicamente en la forma x = g(x). Resolver esta nueva ecuación equivale a encontrar un punto fijo de g: un valor x* tal que g(x*) = x*. A partir de una aproximación inicial x₀, se genera la sucesión:

xn+1 = g(xn)

Condición de convergencia

El teorema del punto fijo establece que si g es continua y derivable en un intervalo que contiene a x*, y si |g'(x)| < 1 en ese intervalo, entonces la iteración converge a x* para cualquier x₀ suficientemente cercano. Si |g'(x*)| > 1, la sucesión se aleja de la raíz en lugar de acercarse.

Esto tiene una consecuencia importante: una misma ecuación f(x) = 0 puede reescribirse de varias formas g(x) distintas, y no todas convergen. La elección del reordenamiento algebraico no es un detalle menor.

El algoritmo

  1. Despejar x = g(x) a partir de f(x) = 0.
  2. Elegir una aproximación inicial x₀.
  3. Calcular xn+1 = g(xn).
  4. Verificar el criterio de parada, por ejemplo |xn+1 − xn| < tol.
  5. Si no se cumple, repetir desde el paso 3.

Un mismo problema, dos reordenamientos

Para f(x) = x² − x − 2 = 0 (raíz real x = 2), una posible reescritura es g(x) = √(x + 2). Cerca de x = 2, g'(x) = 1 / (2√(x+2)) ≈ 0.25, así que |g'(x)| < 1 y la iteración converge. Otra reescritura igualmente válida algebraicamente, g(x) = x² − 2, tiene g'(2) = 4, de modo que |g'(x)| > 1 y la misma idea diverge.

Idea clave

La elección de g determina si el método converge y qué tan rápido lo hace; no toda reorganización algebraica de f(x) = 0 sirve como fórmula iterativa.
