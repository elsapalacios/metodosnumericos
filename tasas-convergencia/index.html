Métodos iterativos para hallar raíces

Resolver f(x) = 0 de forma exacta solo es posible para un puñado de funciones (polinomios de grado bajo, algunas trigonométricas). Para el resto, se recurre a métodos iterativos: en lugar de despejar la raíz, se construye una sucesión x₀, x₁, x₂, … que se espera se acerque cada vez más al valor real x*.

Los tres métodos de esta unidad — bisección, iteración de punto fijo y Newton — comparten esa misma idea general, pero difieren en cómo generan el siguiente término de la sucesión, en qué exigen de la función f y, sobre todo, en qué tan rápido se acercan a la raíz.

Orden de convergencia

Sea eₙ = |xₙ − x*| el error en la iteración n. Se dice que un método converge con orden p si existe una constante C tal que:

lim (n→∞) |en+1| / |en|p = C

Cuanto mayor es p, más rápido decrece el error entre una iteración y la siguiente. p = 1 (con C < 1) se llama convergencia lineal; p = 2, convergencia cuadrática; valores intermedios, como el de la secante, se conocen como superlineales.

MétodoOrden típicoInterpretación práctica
BisecciónLineal (p = 1)El error se reduce a la mitad en cada iteración, sin importar la función.
Punto fijoLineal (p = 1)La rapidez depende de |g'(x*)|: entre más cercano a 0, más rápido.
NewtonCuadrático (p = 2)El número de cifras correctas se duplica aproximadamente en cada paso.

Qué afecta la convergencia

  • La aproximación inicial: partir lejos de la raíz puede hacer que un método converja más lento, oscile, o directamente diverja.
  • El comportamiento de f cerca de la raíz: raíces de multiplicidad mayor a uno, o derivadas cercanas a cero, degradan el orden de convergencia de métodos que asumen condiciones "suaves".
  • La aritmética finita del computador: el error de redondeo impone un límite práctico a cuánto puede reducirse eₙ, sin importar cuántas iteraciones más se realicen.
  • El criterio de parada elegido: detener cuando |xn+1 − xn| < tol, cuando |f(xn)| < tol, o al alcanzar un número máximo de iteraciones, puede dar resultados distintos según el problema.

Idea clave

El orden de convergencia describe un comportamiento asintótico: qué tan rápido decrece el error una vez que ya se está cerca de la raíz. No dice nada sobre las primeras iteraciones ni garantiza que el método vaya a converger.
