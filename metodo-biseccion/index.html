El algoritmo de bisección

El método más simple y confiable para acotar una raíz, basado en el teorema del valor intermedio.

Fundamento matemático

El método de bisección se apoya en el teorema del valor intermedio: si f es continua en [a, b] y f(a) y f(b) tienen signos opuestos, entonces existe al menos un valor c en (a, b) tal que f(c) = 0. Ese cambio de signo garantiza que hay una raíz "atrapada" dentro del intervalo.

El algoritmo

  1. Elegir un intervalo [a, b] tal que f(a) · f(b) < 0.
  2. Calcular el punto medio m = (a + b) / 2.
  3. Si f(m) = 0, o si (b − a) / 2 es menor que la tolerancia deseada, detener: m es la raíz aproximada.
  4. Si f(a) · f(m) < 0, la raíz está en [a, m]: hacer b = m.
  5. En caso contrario, la raíz está en [m, b]: hacer a = m.
  6. Repetir desde el paso 2 con el nuevo intervalo.

Convergencia y número de iteraciones

En cada iteración el ancho del intervalo se reduce exactamente a la mitad, por lo que después de n iteraciones el intervalo mide:

(b − a) / 2n

Esto permite calcular de antemano cuántas iteraciones se necesitan para garantizar una tolerancia dada, despejando n de la desigualdad (b − a) / 2ⁿ < tol. Es un método de convergencia lineal: lento comparado con Newton, pero predecible.

Ventajas y desventajas

  • A favor: siempre converge si el intervalo inicial es válido; no requiere calcular derivadas; es robusto incluso para funciones "difíciles" o con forma irregular.
  • En contra: converge más lento que métodos como Newton; exige encontrar de antemano un intervalo con cambio de signo; no detecta raíces de multiplicidad par, en las que f toca el eje x sin cambiar de signo.

Idea clave

Bisección sacrifica velocidad a cambio de una garantía casi absoluta de convergencia. Por eso suele usarse como método de respaldo, o para obtener una buena aproximación inicial con la que luego arrancar un método más rápido como Newton.
